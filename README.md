# wifi_tool — TUI для подбора пароля WiFi (Windows)

Сканирует сети, читает ключи, которые Windows уже хранит, ловит
PMKID/EAPOL-рукопожатие, конвертирует захват в формат hashcat mode 22000 и
подбирает пароль по словарю — всё в одном терминальном интерфейсе на
[opentui](https://github.com/anomalyco/opentui).

> Используйте только для сетей, к которым у вас есть разрешение.

---

## Установка

Нужен Windows и [uv](https://docs.astral.sh/uv/) — он ставит и нужный Python,
и зависимости, и не требует ничего глобального.

```powershell
git clone https://github.com/falcxe/wifi-hack-tool.git
cd wifi-hack-tool
uv sync
uv run wifi-tool
```

`uv sync` создаёт `.venv` и ставит пакет в него. Дальше — `uv run wifi-tool`,
либо `uv run python main.py`, либо активировать окружение раз и запускать
`wifi-tool` напрямую. Требуется Python 3.12+ — столько просит `opentui`.

Запуск без uv, если он недоступен: `pip install -e .` и `python main.py`.

При первом запуске приложение попросит права администратора — без них
сканирование работает, а захват нет. Автоматический режим всё равно проверит
сохранённые ключи и честно скажет, что не хватает. Чтобы не повышать права
(например, при работе с готовым файлом захвата): `--no-elevate`.

### Зависимости

Всё живёт в `pyproject.toml` и фиксируется `uv.lock` — обновлять нужно оба.

| Пакет | Без него |
|---|---|
| `opentui` | не запускается ни приложение, ни тесты |
| `pyserial` | **плата не определяется**: `find_boards()` возвращает пустой список, пункт «Захваты с платы» в F1 всегда неактивен, стик не виден даже воткнутым |
| `scapy` | «Отвалить клиентов» молча выключается, остальной захват работает |
| `py7zr` | распаковка hashcat-архива средствами Python; при BCJ2 всё равно нужен `assets\7zr.exe` |
| `pillow` | только для `tools/preview_motion.py`; в группе `dev`, ставится через `uv sync` |

Про `pyserial` стоит знать отдельно: плата, которой нет в списке портов, почти
всегда означает именно его отсутствие, а не проблему с USB.

```powershell
python -c "from wifi_tool import bruce; print(bruce.available(), bruce.find_boards())"
```

`False` в первом месте — не установлен `pyserial`. Пустой список при `True` —
порт есть, но USB-ids не совпали с известными платами (см. `KNOWN_USB_IDS` в
`wifi_tool/bruce.py`).

## Как пользоваться

Основной маршрут: **Сети → Проверка сети → Параметры → Выполнение →
Результат**. Всё задаётся внутри интерфейса.

**Быстрый путь:** выделил сеть → **Enter** (отчёт) → **Enter** (подбор) →
результат.

На экране отчёта открой меню **F1** или стрелкой **→**, выбери **«Параметры»**,
чтобы задать источник данных, метод и лимит вручную. В поле **Источник**
выбирается живой захват или готовый файл; в поле **Захват** — файл `.pcap`,
`.pcapng`, `.cap` или `.22000`. **F1 → Проверить** читает окружение и
разбирает файл: показывает, нашлись ли EAPOL или PMKID, и называет причину,
если нет.

### Клавиши

| Клавиши | Действие |
|---|---|
| **Enter** | открыть выбранную сеть или выполнить выделенное действие |
| **Esc** | закрыть верхнее окно или вернуться назад; на главном экране открыть меню |
| **F1** | меню команд текущего экрана |
| **↑ ↓** | строки активного списка, поля формы, действия или журнал |
| **Tab / Shift+Tab** | следующий / предыдущий элемент или область |
| **← →** | курсор в поле; в списке файлов — родительская / выбранная папка |
| **PageUp / PageDown** | страница списка, документа, меню или журнала |
| **Home / End** | начало / конец списка; в поле — начало / конец текста |
| `/` | поиск по SSID, BSSID, защите и каналу |
| колесо мыши | прокрутка списка по три строки |

Для отключения анимации: `WIFI_TOOL_REDUCED_MOTION=1` перед запуском.

### Автоматическая лестница

**Enter** на экране аудита запускает подбор по лестнице, которая платит этапам
по порядку вероятности и останавливается на первом успехе:

| # | Этап | Что проверяется |
|---|---|---|
| 1 | ключ Windows | сохранённый профиль этой сети, мгновенно |
| 2 | захват | PMKID или рукопожатие, до 60 с |
| 3 | кандидаты по имени и MAC | SSID, MAC, заводские пароли + цифры |
| 4 | частые пароли | probable-wpa.txt, 4 800 |
| 5 | RockYou WPA | rockyou-wpa.txt, 9,6 млн |
| 6 | RockYou + мутации | best66.rule, ~620 млн |
| 7–8 | цифры 8–9 | маски `?d…`, 10⁸ / 10⁹ |

Полный проход ≈ 42 минуты на 684,5 kH/s. План печатается в журнал до старта,
**Esc** открывает окно остановки.

Метода, дающего 100 %, у WPA2 нет — это следствие самого PBKDF2. Если пароль
случайная строка из 16 символов, её нет ни в одном из этапов, и результат будет
«не найден».

## Что положить в `assets/`

Всё, что лежит в `assets/`, подхватывается автоматически.

| Файл | Зачем | Как поставить |
|---|---|---|
| `hashcat.exe` | подбор пароля | распакуй официальный архив — путь `hashcat-<версия>/hashcat.exe` находится сам |
| `rockyou-wpa.txt` / `probable-wpa.txt` | словари | выбираются в TUI; источники — [RockYou](https://github.com/danielmiessler/SecLists/blob/master/Passwords/Leaked-Databases/rockyou.txt.tar.gz) и [Probable WPA](https://github.com/danielmiessler/SecLists/blob/master/Passwords/WiFi-WPA/probable-v2-wpa-top4800.txt) |
| `netcap80211.exe` или `tshark.exe` | захват рукопожатия | см. «Захват» ниже |
| `wpawolf.exe` | конвертер хэшей | автоматически, клавишей **D** на экране настройки и подбора |

Правила мутаций (`best66.rule`) берутся из поставки hashcat, если не положить
свои в `assets/rules/`.

### Распаковка hashcat

Архив `.7z` может использовать BCJ2, которое не понимает `py7zr`. Нужен
настоящий 7-Zip — один файл, без установки:

```powershell
curl -o assets/7zr.exe https://www.7-zip.org/a/7zr.exe
assets\7zr.exe x -y -oassets Downloads\hashcat-7.1.2.7z
```

## Захват рукопожатия

Windows обычно отдаёт программе обычные данные с заголовками Ethernet. Для
кадров 802.11 из эфира нужен **Npcap с поддержкой raw 802.11** и адаптер или
драйвер с режимом монитора. Само наличие Wireshark этого не гарантирует.
[Документация Wireshark](https://wiki.wireshark.org/CaptureSetup/WLAN),
[инструкция Npcap](https://npcap.com/guide/npcap-users-guide.html).

Встроенный адаптер Intel AX211 монитор-режим не поддерживает — живой захват на
нём невозможен, и приложение говорит об этом до запуска, а не после.

Отсюда два пути:

* **адаптер с режимом монитора** (Alfa AW036ACH, MediaTek MT7612U) — приложение
  само определит доступный инструмент при следующем запуске;
* **плата ESP32 с прошивкой Bruce** (M5StickC) — радио делает захват
  promiscuous сама. В F1 появляется **«Захваты с платы»**: читает сохранённые
  на стике файлы, показывает число пар EAPOL и PMKID и обновляет копии в
  `captures`.

### Если адаптер не умеет монитор

Разбери уже готовый файл — права администратора не нужны:

```powershell
python main.py --file path/to/capture.pcapng
```

Поддерживаются `.pcap`, `.pcapng` и `.22000`. Файл можно получить через
Wireshark (`tshark -i <интерфейс> -I <канал> -a duration:120 -w own.pcapng`)
или с телефона с root. Готовый `.22000` выбирается напрямую, конвертер не нужен.

### Отвалить клиентов

Пассивный захват ловит рукопожатие только когда клиент сам решил
переподключиться. В параметрах, в разделе «Дополнительно» для живого захвата,
есть **«Отвалить клиентов»** — отправка кадра деаутентификации, после чего
клиент переподключается за секунды. Выключено по умолчанию: связь пропадает у
всех устройств этой сети. Нужен `scapy`, права администратора и адаптер с
режимом монитора; сеть с 802.11w деаут проигнорирует.

## Параметры командной строки

| Параметр | Значение |
|---|---|
| `--auto` | автоматический режим без вопросов; то же, что **Enter** на экране аудита |
| `--file PATH` | готовый захват `.pcap`/`.pcapng`/`.22000` вместо сканирования |
| `--wordlist PATH` | свой словарь кандидатов |
| `--mask MASK` | маска hashcat, например `MyHome?d?d` |
| `--rules PATH` / `--no-rules` | файл мутаций / проверка без них |
| `--runtime SECONDS` | лимит подбора, по умолчанию 600 |
| `--bssid AA:BB:CC:DD:EE:FF` | одна целевая точка доступа в захвате |
| `--no-elevate` | не спрашивать права администратора |

`--auto` нельзя сочетать с `--wordlist`, `--mask` или `--no-rules` — это два
описания одного прогона, и приложение скажет об этом, а не выберет молча.
Словарь и маска — разные режимы; правила применяются только к словарю. Если в
файле несколько точек доступа, нужно указать `--bssid`.

Параметры масок и статуса описаны в
[документации hashcat](https://hashcat.net/wiki/?id=hashcat).

## Тесты

Все тесты в `tests/`, запускаются как модули:

```powershell
uv run python -m tests.run_ui_tests    # весь интерфейс: 191 тест, без внешних инструментов
uv run python -m tests.test_parser     # разбор вывода netsh: RU/EN, обе кодировки, живой скан
uv run python -m tests.test_profiles   # чтение сохранённых профилей
uv run python -m tests.test_hc22000    # встроенный конвертер: 802.11 / radiotap / Ethernet
uv run python -m tests.test_groundtruth # сверка с wpawolf на реальных захватах
uv run python -m tests.test_auto       # автолестница: кандидаты, бюджет, реальный hashcat
uv run python -m tests.test_e2e        # полный цикл: захват -> hc22000 -> hashcat -> пароль
uv run python -m tests.test_smoke      # живой TUI: настоящий ввод и настоящий netsh
```

`tests.test_e2e` и `tests.test_auto` запускают настоящий hashcat по хэш-файлу,
который произвёл конвертер этого проекта, и требуют, чтобы пароль `12345678`
(задокументирован в имени фикстуры) был найден. Фикстуры лежат в
`tests/fixtures/`.

Отдельный модуль — `./tools/run_one.ps1 tests.test_ui` — прогоняет один модуль
и печатает только строки с ошибками.

## Инструменты разработчика

В `tools/` лежат скрипты, которые не участвуют в работе приложения:

```powershell
uv run python tools/preview.py --export ui_artifacts/frames   # headless-кадры всех экранов в PNG
uv run python tools/preview_motion.py                        # анимация в GIF из настоящих кадров
uv run python tools/catch.py --crack                         # поймать рукопожатие платой и подобрать
```

`tools/catch.py` дублирует то, что делает TUI, но с обратным отсчётом и
подсказками вслух — так видно, что делать с телефоном, пока идёт ожидание.

## Ограничения

* Захват требует драйвера, умеющего raw 802.11. Встроенный адаптер Intel AX211
  его не поддерживает.
* Для WPA3/SAE переходов EAPOL может быть зашифрован — извлекается не всё.
* Встроенный конвертер не проверяет мусорные шаблоны так, как это делает
  wpawolf, поэтому на некоторых захватах выдаёт лишние (не ломающие) записи.
  Основной конвертер — wpawolf; встроенный включается сам, если бинарника нет.
* После захвата адаптер может остаться в raw-режиме и перестать сканировать.
  Приложение возвращает ему обычный режим после каждого захвата; если
  интерфейс всё же выглядит отключённым — переподключите адаптер по USB.
